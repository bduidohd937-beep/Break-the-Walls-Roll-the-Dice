# 성벽을 부수고 주사위를 던져라

React + TypeScript + Vite로 만든 2D 횡스크롤 자동 전투, 영지 경영, 영웅 수집 **프로토타입**입니다. 현재 이모지와 성·배경 도형은 임시 그래픽입니다.

## 로컬 실행

```powershell
npm install
npm run dev
npm run build
```

## 현재 구현 범위

- 왼쪽 아군 성에서 영웅을 반복 출격시켜 오른쪽 적 성을 공략합니다. 최대 10명 편성, 전장 아군 최대 50명, 전투 UI는 5명씩 페이지로 표시합니다.
- Battle Gold는 전투에서만 사용합니다. Game Gold는 영지와 영웅 성장에, Gem은 영웅 소환에 사용합니다.
- 소환 10+1은 11회이며 결과는 저장소로 이동합니다. `???` 등급은 일반 소환에서 나오지 않습니다.
- 영지 시설, 자동 채집과 최대 8시간 오프라인 생산, 스테이지 1~50 기본 구조, 보스 전투, 첫 클리어와 반복 보상이 들어 있습니다.
- 스테이지 일반 데이터, 성장·보상 수치, 영웅 구성, 합성 레시피는 대부분 임시입니다. 합성소에서 현재 실제 영웅을 지급하는 레시피는 손오공뿐이며 다른 레시피는 준비 중입니다.
- 9스테이지 기간토스는 전용 적 엔티티로 등장하지만 세부 전투 능력치는 임시입니다.

## 개발자 테스트

개발 서버는 기본적으로 개발자 데이터 프로필을 사용합니다. 일반 프로필은 `?dev=0`, 배포 환경의 개발자 프로필은 `?dev=1`을 URL에 붙여 엽니다. 두 프로필은 서로 다른 localStorage 키에 저장됩니다. 브라우저에서 localStorage를 지우면 해당 출처의 저장 데이터가 사라집니다.

기본 회귀 확인: 첫 클리어·재클리어 보상, 9·20·30·40·50 보스 등장 및 처치, AUTO COM, 편성·소환·저장소·합성, 재접속 후 저장 유지.
