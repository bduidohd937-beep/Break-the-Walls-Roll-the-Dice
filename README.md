# 성벽을 부수고 주사위를 던져라

2.5D 복셀 방치형 타이쿤 + 디펜스 + 경영 시뮬레이션 프로토타입.

## 1차 패치

- React + TypeScript + Vite
- Three.js 기반 쿼터뷰 복셀 영지
- 나무/바위 클릭 채집
- 목재/석재/골드 자원 HUD
- 상점 판매
- LocalStorage 저장
- 성/상점/영지 기본 씬

## 로컬 실행

```powershell
npm install
npm run dev
```

개발 서버 주소는 터미널에 표시되는 Vite 주소를 열면 됩니다.

## 다음 확장 예정

장비 가챠 → 인부 자동화 → 농장/공장 → 성 업그레이드 → 냥코식 라인 디펜스 → 골든 티켓/카지노 → 무한 스테이지.
